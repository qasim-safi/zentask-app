## ✨ Features

- ➕ **Add Tasks** — With title, category, priority level, and due date
- ✏️ **Edit Tasks** — A smooth modal editor to update any task
- 🗑️ **Delete Tasks** — Animated slide-out on removal
- ✅ **Complete Tasks** — Tap the circle checkbox to mark done
- 📁 **Categories** — Work, Personal, Study, Health — each with a color badge
- 🔴 **Priorities** — High / Medium / Low with a colored indicator bar
- 📅 **Due Dates** — Overdue dates highlighted in red, today in amber
- 🔍 **Filter & View** — All / Today / Completed / by Category
- 📊 **Progress Ring** — Visual completion rate in the top-right
- 💾 **Persistent Storage** — All tasks saved to `localStorage`
- 📱 **Responsive Design** — Collapsible sidebar on mobile

| Key | Action |

| `Escape` | Close modal |
